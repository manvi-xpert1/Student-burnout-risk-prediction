# Student Wellness Index and Burnout Prediction Model

Code and research paper for our project on predicting student academic burnout using a Student Wellness Index (SWI) and machine learning (Random Forest, SVM, Logistic Regression).

## Files

- `Final_project.ipynb` — Colab notebook with the full analysis
- `STUDENT_WELLNESS_INDEX_AND_BURNOUT_PREDICTION_MODEL.docx` — research paper

## How to run

1. Open `Final_project.ipynb` in Google Colab.
2. Upload `data.csv` (survey data) to the Colab session.
3. Run all cells.

## Requirements

numpy, pandas, matplotlib, seaborn, scikit-learn, scipy, statsmodels, pingouin, joblib
